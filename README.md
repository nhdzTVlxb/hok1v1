除了这个情况有点难以改变，由于今年（2026）加入了服务外包的赛制，槽点还是挺多的  
总体来说，作为第一次参赛solo并且第一次接触RL的learner来说，打到这个成绩还是比较满足的，因为放到全国或者其他赛区，还是比较有竞争力的，今年看来就东部和北部赛区比较强。  
下面来讲讲复盘细节：  

首先RL里面feature和reward是最重要的，model部分能去吃透就行吧，这里不建议用lstm和RNN，建议使用GRU（轻量高效，性价比高），然后就是环境参数的设定，如生产消耗比，熵系数；以及reward参数的调整，让你的agent偏激进还是策略。  
model和reward部分建议参考以前的baseline，基本接近最优了，一般后来的选手很难去复现；  
初期建议在test_train里面去抓obs字段，文档里的信息量还是比较少的，甚至是有错误的。  
前期可以用一个小维度的agent去做一些debug，输出一些特定帧，看看你的feature是否写对，以为反馈的action是否满足你的期望。  
feature有写600～4000的都有，主要看你model能不能吃透，然后重点是不断更新你的评估队手（用你上一代的agent）不断迭代，不要只看common_ai  
然后就是训练步数，我最后只花了一个星期的时间训练，训练到了12w步，在我前面的五位选手都是40w-50w+的一个部署，这块应该是最后决定性的原因。  
所以尽早定下来前面所说的问题，然后不断迭代，调参，长期训练。
